# 🎮 HoKOS Gaming Support

## Supported Games
- Punishing Gray Raven (Mobile via Waydroid)
- Honor of Kings (Mobile via Waydroid)
- Genshin Impact (PC via Proton/Wine)
- Honkai Series (Mobile via Waydroid, PC via Proton)

## Requirements
- Latest Vulkan drivers (Intel ARC, AMD Radeon, NVIDIA RTX)
- Waydroid for Android games
- Proton-GE for PC games
- Gamemode for performance boost

## Notes
- Android titles run best inside Waydroid with GPU passthrough enabled.
- PC titles like Genshin/Honkai require Proton-GE and may need configuration tweaks.
- Input method: install `fcitx5` with Chinese Pinyin for in-game chat.
